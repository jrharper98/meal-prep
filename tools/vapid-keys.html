VAPID key generator

Runs entirely in this browser; nothing is sent anywhere. Generate once, then:

  1. Paste the public key into VAPID_PUBLIC_KEY in index.html.
  2. Save both keys as Edge Function secrets: VAPID_PUBLIC_KEY and VAPID_PRIVATE_KEY.
  3. Don't commit the private key anywhere public. If you generate new keys later, turn reminders off and on again on each device.
